# همیار سلامت

دستیار فارسی و آفلاین سلامت کار اداری برای Windows 11 x64، با فونت یکان، آیکون اختصاصی و رابط شیشه‌ای کوچک.

[دانلود نسخهٔ جدید](https://github.com/sayyedalimrj/Ergonomy/releases)

- نسخهٔ قبلی را از آیکون کنار ساعت خارج کنید.
- نصب یا نسخهٔ قابل‌حمل را اجرا کنید؛ نشان سایه‌دار لبهٔ راست محل بازشدن کارت را نشان می‌دهد.
- از + به کتابخانهٔ حرکت، زمان‌بندی/یادآور شخصی و درباره دسترسی دارید.
- فیلترهای دکمه‌ای، چک سریع میز کار و انیمیشن نرم فقط هنگام نمایش فعال‌اند.
- هر حرکت تایمر مستقل، قبلی/بعدی، مکث/ادامه و تکرار دارد.
- پیش‌فرض‌ها خودکارند؛ دوربین، تشخیص وضعیت بدن، ثبت کلید یا سرویس ابری وجود ندارد.

[ویژگی‌ها، منابع و دامنهٔ تست](docs/POLISH-V7.md) · [تغییرات](CHANGELOG.md)

بسته آزمایشی و امضانشده است. زمان‌های آموزشی الزام قانونی یا برنامهٔ درمانی نیستند. ارزیابی واقعی چند نمایشگر و مصرف طولانی همچنان باقی است.

```powershell
dotnet run --project tests/Ergonomy.EngineTests -c Release
dotnet build src/Ergonomy/Ergonomy.csproj -c Release
```

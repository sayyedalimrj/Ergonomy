# Ergonomy

A privacy-first, configurable Windows desktop companion for office ergonomics, eye breaks, posture checks, and movement reminders.

Status: initial research and prototype development (not a certified medical device or a substitute for workplace HSE assessment).

This repository is being developed against HSE DSE, OSHA computer workstation, NIOSH, AOA/AAO, ISO 9241-5:2024, and EU Directive 90/270/EEC guidance. Intervals are configurable recommendations, not universal legal thresholds.

See the `feat/windows-hse-mvp` branch / pull request for the initial application implementation and documentation.

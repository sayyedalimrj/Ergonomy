# Changelog

## 0.3.0-rc.1 — 2026-11-07

- Retain and extend glass dock v2 on WPF/.NET 10.
- Add four native vector buddies, seven states, visibility/idle/reduced-motion gating.
- Extract deterministic scheduler; add 17 behavioral assertions; isolate manual practice from automatic cycles.
- Suppress dock and delivery via fullscreen bounds and public shell notification state.
- Handle power/session events, drag/persist/clamp placement, PerMonitorV2, narrow header and wrapping navigation.
- Add per-category enable/interval settings, opt-in startup, bounded local outcome history and clear control.
- Add Skip/timeout, keyboard-focus styling, nonactivating auto-open and interactive focus restoration.
- Add Windows render smoke, per-user installer, portable installation/removal, pilot resource harness and prerelease workflow.
- Add Figma buddy component system and interactive MagicPath reference.

Known gaps: native backdrop blur/light theme/provider-specific meeting detection; Windows 11 physical desktop acceptance, accessibility and resource profiling remain unverified. Unsigned candidate.
